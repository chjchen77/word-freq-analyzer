中文文本词频统计分析工具 — Windows 版

使用方法
1. 将整个“词频统计分析工具”文件夹解压到本地磁盘。
2. 双击“词频统计分析工具.exe”启动程序。
3. 在“数据选择”中添加包含 .xlsx / .xls / .csv / .txt 文件的文件夹。
4. 按界面提示导入词典、选择列并运行分析。

注意事项
- 请保持 exe 文件和同一文件夹中的所有文件、子文件夹不变，不要单独拷贝 exe。
- 本版本适用于 64 位 Windows 10 / 11，不需要另外安装 Python。
- 第一次打开如果出现 Windows 安全提示，请选择“更多信息”→“仍要运行”。
- 启用大语言模型分析时，需要在程序中填写自己的 API 配置；普通词频统计无需 API。
