中文文本词频统计分析工具 v4.2.0 — Windows 版

使用方法
1. 推荐运行 `词频统计工具-Windows-x64-Setup.exe`，按向导完成安装。
2. 如果使用便携版，请将整个 ZIP 解压到本地磁盘，再双击文件夹内的“词频统计分析工具.exe”。
3. 在“数据选择”中添加包含 .xlsx / .xls / .csv / .txt 文件的文件夹。
4. 按界面提示导入词典、选择列并运行分析。

注意事项
- 便携版必须保持 exe 文件和同一文件夹中的所有文件、子文件夹不变，不要单独拷贝 exe。
- 本版本适用于 64 位 Windows 10 / 11，不需要另外安装 Python。
- 第一次打开如果出现 Windows 安全提示，请选择“更多信息”→“仍要运行”。正式签名版本发布后该提示会减少。
- 启用大语言模型分析时，需要在程序中填写自己的 API 配置；普通词频统计无需 API。
