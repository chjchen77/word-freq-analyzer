# 中文文本词频统计分析工具 v4.2.0

科研级中文文本词频统计工具。默认逐条保留原始记录，识别日期中的年份和月份，不按年份或月份合并；也可切换为公司×月份或公司×年份汇总。

## 核心功能

- 支持 `.xlsx` / `.xls` / `.csv` / `.txt` 数据文件，自动递归扫描子文件夹
- Excel 自动识别工作表和表头行，扫描后提供列映射与年月识别质量检查
- 支持分类词典管理（多分类、多关键词；多选批量删除、实时搜索、分类重命名）
- 双模式匹配：**正则匹配**（推荐）和 **jieba 中文分词**
- 大文件自动分块处理（`.xlsx` 流式读取，CSV > 100MB 自动分块读取）
- 多线程并发文件处理（可配置工作线程数，M4 Pro 推荐 4–8）
- 输出 Excel 原始记录统计（多 Sheet），含日期、月份、来源文件、源文件行号、分类统计、关键词明细、词典诊断、分析说明
- 逐条模式可选择保留公司简称、调研机构等原始字段；结果附带数据质量、异常记录、输入文件指纹和运行元数据
- 支持逐条原始记录、公司×月份汇总、公司×年份汇总三种统计粒度
- 支持分类占比标准化、停用词过滤、命中句子导出
- **大语言模型句子分析**：对命中句子自动标注时间指向、语态、句子类型、确定性、量化属性、语气、置信度（支持 Qwen / 任意 OpenAI 兼容接口，带本地缓存）
- 自动识别股票代码（含 .SH/.SZ/.BJ 后缀剥离）和日期列
- 超大数据集自动截断保护 + 完整 CSV 备份

## 系统要求

- macOS 10.15 (Catalina) 或更高版本
- Windows 10 / 11（64 位）
- Python 3.10+（从源码运行时）
- 建议内存 8GB 以上（处理大文件时建议 16GB）

## 快速开始

### 方式一：下载预编译程序（推荐）

前往 [Releases](https://github.com/chjchen77/word-freq-analyzer/releases) 页面下载对应系统的安装包：

- **Windows 便携版**：下载 `词频统计工具-v4.2.0-Windows-x64.zip`，解压后双击文件夹内的 exe
- **Windows 安装版**：下载 `词频统计工具-Windows-x64-Setup.exe`，按向导安装
- **macOS Intel**：下载带 `macOS-x86_64` 的 ZIP
- **macOS Apple Silicon**：下载带 `macOS-arm64` 的 ZIP

> macOS 首次打开可能提示「无法验证开发者」，右键点击 → 选择「打开」→ 点击「打开」即可。

### 方式二：从源码运行

```bash
# 克隆仓库
git clone https://github.com/chjchen77/word-freq-analyzer.git
cd word-freq-analyzer

# 安装依赖
pip install -r requirements.txt

# 运行程序
python word_freq_analyzer.py
```

## 项目结构

- `word_freq_analyzer.py`：桌面入口与统计流程
- `wordfreq_app/`：版本、设置、Excel 布局识别、数据质量和更新检查服务
- `packaging/`：Windows 版本信息与安装程序脚本
- `run_server.py`：本地服务启动入口
- `run_full_wordfreq.py`、`run_dual_scoring.py`：批量词频与双轨评分脚本
- `extract_mda_*.py`、`count_mda_sentences.py`：年报文本抽取与句子统计工具
- `rubrics/`：外置评分规则
- `tests/`：自动化回归测试
- `.local/`：本地运行结果和缓存，不参与版本管理
- `dist/`：本地打包产物，不参与版本管理

运行测试：

```bash
pytest -q
```

## 使用说明

程序界面分为 4 个标签页：

1. **数据选择** — 添加文件夹，自动识别工作表/表头，配置公司代码列、日期/年份列、文本列和需要保留的原始字段；支持质量抽查
2. **词典管理** — 导入或手动创建分类词典；支持多选批量删除、实时搜索、分类重命名、全选/清空本类
3. **分析设置** — 逐条原始记录、公司×月份或公司×年份汇总，匹配模式、输出选项、停用词、并发线程数、LLM 句子分析、输出路径
4. **运行分析** — 开始统计，实时进度条和彩色日志，支持随时取消

### 词典格式

**Excel 词典**（`.xlsx` / `.xls`）：两列表格，第一列为分类名，第二列为关键词。

| 分类 | 关键词 |
|------|--------|
| 低碳战略 | 碳中和 |
| 低碳战略 | 碳达峰 |
| 绿色创新 | 绿色技术 |

**文本词典**（`.txt`）：每行一个分类，冒号分隔。

```
低碳战略：碳中和,碳达峰,低碳转型
绿色创新：绿色技术,清洁能源,节能减排
```

### 年报 TXT 文件命名规范

支持直接读取年报纯文本文件，文件名格式：

```
000001_2022_公司名_标题_日期.txt
```

程序自动从文件名中解析公司代码（6 位数字）和年份（4 位数字）。

### 输出文件

| Sheet | 内容 |
|-------|------|
| 原始记录统计 | 每条有效原始记录的日期、月份、来源信息及分类统计（默认） |
| 原始记录关键词 | 每条原始记录中各关键词的出现次数及所属分类 |
| 分类汇总 | 各分类总次数和占比 |
| 数据质量 | 每个输入文件的行数、年月识别率、空代码、空文本和命中次数 |
| 异常记录 | 无效代码、无效年份、未知月份和空文本的异常样本 |
| 输入文件清单 | 输入文件大小、修改时间和可复核文件指纹 |
| 运行元数据 | 软件版本、统计方式、列配置、词典指纹和运行环境 |
| 词典诊断 | 跨分类重复关键词检查报告 |
| 分析说明 | 计数规则与方法论说明 |
| 独立命中句子文件 | 可选输出为同名 `_sentences.xlsx`；超出 Excel 上限时另存完整 CSV，启用 LLM 后追加标注列 |

### LLM 句子分析

启用后，对每条命中句子调用大语言模型（默认 Qwen），追加以下标注列：

| 列名 | 取值示例 |
|------|----------|
| LLM时间指向 | 过去 / 现在 / 未来 / 不确定 |
| LLM语态 | 主动 / 被动 / 不确定 |
| LLM句子类型 | 陈述句 / 承诺句 / 意图句 / 条件句 / 不确定 |
| LLM确定性 | 确定 / 不确定 |
| LLM量化属性 | 定量 / 半定量 / 定性 |
| LLM语气 | 正面 / 中性 / 负面 |
| LLM置信度 | 高 / 中 / 低 |
| LLM分析状态 | 成功 / 跳过 / 失败 / 已取消 |

支持本地 SQLite/JSON 缓存：相同句子重复运行自动跳过，节省 API 费用。每句约消耗 200–500 token。

## 依赖

- [pandas](https://pandas.pydata.org/) >= 2.0.0 — 数据处理
- [openpyxl](https://openpyxl.readthedocs.io/) >= 3.0.0 — Excel 读写
- [xlrd](https://xlrd.readthedocs.io/) >= 2.0.1 — .xls 文件读取
- [jieba](https://github.com/fxsjy/jieba) >= 0.42.1 — 中文分词（仅 jieba 模式时加载）
- [openai](https://github.com/openai/openai-python) >= 1.0.0 — LLM 接口（仅启用 LLM 分析时使用）
- [xlsxwriter](https://xlsxwriter.readthedocs.io/) >= 3.0.0 — 大数据量 Excel 结果写出
- [keyring](https://github.com/jaraco/keyring) >= 25.0.0 — 可选的系统凭据服务，用于安全保存 API Key

发布构建使用 [requirements-lock.txt](requirements-lock.txt) 锁定版本；开发测试使用 [requirements-dev.txt](requirements-dev.txt)。
