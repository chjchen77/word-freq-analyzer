一、软件简介
================================================================

本工具用于对中文文本进行词频统计分析，输出「公司×年份」面板数据
格式，适合学术研究和数据分析。

核心功能：
  - 支持 .xlsx / .xls / .csv 数据文件，自动递归扫描子文件夹
  - 支持分类词典管理（多分类、多关键词）
  - 双模式匹配：正则匹配（推荐）和 jieba 中文分词
  - 大文件自动分块处理（CSV > 100MB 自动分块读取）
  - 输出 Excel 面板数据（多 Sheet），含分类统计和关键词明细
  - 支持 TF 词频标准化、停用词过滤、命中句子导出
  - 自动识别股票代码和日期列
  - 超大数据集自动截断保护 + 完整 CSV 备份

系统要求：
  - macOS 10.15 (Catalina) 或更高版本
  - Windows 10 / 11（64 位）
  - 建议内存 8GB 以上（处理大文件时建议 16GB）

二、macOS 安装说明
================================================================

方式 A：使用预编译应用（推荐，无需安装 Python）
------------------------------------------------

1. 获取安装包
   在 dist 文件夹中找到：
     - 词频统计分析工具_macOS.zip    （压缩包，约 91MB）
     - 词频统计分析工具.app           （应用程序）

2. 安装步骤
   (a) 如果收到的是 .zip 文件，双击解压得到 .app 文件
   (b) 将「词频统计分析工具.app」拖入「应用程序」文件夹
       （也可以放在桌面或任意位置直接使用）

3. 首次运行
   双击「词频统计分析工具.app」启动程序。

   ** 重要：首次打开可能提示「无法打开」或「未知开发者」 **
   解决方法：
     方法一：右键点击 .app → 选择「打开」→ 点击「打开」确认
     方法二：前往「系统设置」→「隐私与安全性」→ 找到提示 →
             点击「仍要打开」

4. 卸载方式
   将 .app 文件拖入废纸篓即可。


方式 B：使用脚本从源码构建
--------------------------

1. 确保已安装 Python 3.10 或更高版本：
     python3 --version

2. 打开「终端」应用，进入软件目录：
     cd /path/to/词频统计工具

3. 运行构建脚本：
     chmod +x build_app.sh
     ./build_app.sh

4. 构建完成后在 dist 文件夹找到 .app 文件

三、Windows 安装说明
================================================================

方式 A：使用预编译程序（推荐，无需安装 Python）
------------------------------------------------

  ** 注意：Windows 版 .exe 需要在 Windows 电脑上构建 **
  ** 如果已有他人构建好的 .exe，直接使用即可 **

1. 获取安装包
   找到 dist 文件夹中的：词频统计分析工具.exe

2. 安装步骤
   无需安装。将 .exe 文件复制到任意目录即可使用。
   建议放在：C:\Users\你的用户名\Desktop\ 或专用文件夹中。

3. 首次运行
   双击「词频统计分析工具.exe」启动程序。

   ** 首次运行说明 **
   (a) Windows Defender SmartScreen 可能弹出蓝色警告窗口
       → 点击「更多信息」→ 点击「仍要运行」
   (b) 首次启动可能较慢（约 10-30 秒），这是正常的解压过程
   (c) 如果杀毒软件误报，请将 .exe 添加到白名单/排除列表

4. 卸载方式
   直接删除 .exe 文件即可。


方式 B：在 Windows 上从源码构建 .exe
--------------------------------------

1. 安装 Python 3.10 或更高版本
   下载地址：https://www.python.org/downloads/
   安装时务必勾选「Add Python to PATH」

2. 将整个「词频统计工具」文件夹复制到 Windows 电脑

3. 双击 build_windows.bat 运行构建脚本
   或者打开命令提示符（CMD）：
     cd C:\path\to\词频统计工具
     build_windows.bat

4. 等待构建完成（约 2-5 分钟），在 dist 文件夹找到 .exe


方式 C：直接运行 Python 源码（无需打包）
-----------------------------------------

1. 安装 Python 3.10+，并确保已添加到 PATH

2. 打开命令提示符，安装依赖：
     pip install jieba pandas openpyxl xlrd

3. 进入软件目录运行：
     cd C:\path\to\词频统计工具
     python word_freq_analyzer.py

五、使用教程（详细步骤）
================================================================

程序界面分为 4 个标签页，请按顺序操作：


【第一步：数据选择】
--------------------

1. 添加文件夹
   点击「添加文件夹」按钮，选择存放数据文件的文件夹。
   - 支持同时添加多个文件夹
   - 程序会自动递归扫描所有子文件夹
   - 支持的文件格式：.xlsx、.xls、.csv

2. 扫描文件
   点击「扫描文件」按钮：
   - 自动列出所有找到的数据文件
   - 自动读取文件列名
   - 自动识别常用列名（如 Scode、Qtm、Reply 等）
   - 显示每个子文件夹中的文件数量

3. 配置列映射
   根据您的数据设置三个关键列：

   (a) 公司代码列：选择包含股票代码/公司代码的列
       常见列名：Scode、股票代码、证券代码、code
       系统会自动补零为 6 位（如 1 → 000001）

   (b) 年份/日期列：选择包含年份或日期的列
       常见列名：Qtm、年份、year、日期、date
       支持多种格式：纯年份(2020)、日期(2020-03-15)、
       混合格式等，系统自动识别

   (c) 文本列：选择包含要分析文本的列（可多选）
       常见列名：Reply、回复、文本、内容
       按住 Ctrl/Cmd 键可选择多列，多列内容会自动合并

4. 预览数据
   点击左侧文件列表中的文件名，下方会显示前 100 行数据预览，
   方便确认列名和数据格式。


【第二步：词典管理】
--------------------

设置要统计的关键词及其分类。

1. 方式一：导入已有词典（推荐）
   点击「导入词典」按钮，选择词典文件。
   支持两种格式（见下方「词典格式说明」）。

2. 方式二：手动创建词典
   (a) 点击「添加分类」，输入分类名称（如「低碳战略」）
   (b) 选中分类后，点击「添加关键词」逐个添加
   (c) 或点击「批量添加」，每行输入一个关键词

3. 管理词典
   - 导出词典：将当前词典保存为 Excel 文件，方便备份和分享
   - 新建词典：清空当前词典重新开始
   - 删除分类/关键词：选中后点击对应删除按钮


【第三步：分析设置】
--------------------

1. 匹配模式
   - 正则匹配（推荐）：直接在文本中搜索关键词，不区分大小写。
     速度快，适合大多数场景，尤其是含英文词的词库。
   - jieba 分词：先用中文分词切词，再匹配词典。
     更精准但较慢，适合纯中文精细分析。

2. 停用词（仅 jieba 模式生效）
   - 勾选启用后，过滤"的、了、在"等无意义词语
   - 可追加自定义停用词文件（每行一个词）

3. 输出选项
   - TF 标准化词频：在 Sheet1 中添加 TF 列，计算每个分类
     的词频占比（分类词频 / 总命中数）
   - 导出命中句子：提取包含关键词的原文句子，输出到 Sheet4，
     可用于论文引用和结果验证

4. 输出文件路径
   点击「选择路径」，指定输出 Excel 文件的保存位置。
   如不设置，系统会自动建议一个路径。


【第四步：运行分析】
--------------------

1. 点击「开始统计」按钮启动分析

2. 运行过程中：
   - 进度条显示整体进度
   - 日志区域实时显示每个文件的处理情况
   - 可随时点击「取消」中止分析

3. 分析完成后：
   - 弹出提示框显示完成信息
   - 日志中显示统计摘要（面板记录数、公司数、年份范围等）
   - 结果自动保存到指定路径

4. 性能参考：
   - 正则模式处理 100 个 xlsx 文件（约 50 万行）：约 2-5 分钟
   - jieba 模式通常慢 5-10 倍
   - 大 CSV（>100MB）自动分块处理，不会内存溢出

六、词典格式说明
================================================================

格式一：Excel 词典（.xlsx / .xls）
------------------------------------
  两列表格，第一列为分类名，第二列为关键词，每行一个词。

  示例：
  ┌──────────────┬──────────────┐
  │     分类     │    关键词    │
  ├──────────────┼──────────────┤
  │ 低碳战略     │ 碳中和       │
  │ 低碳战略     │ 碳达峰       │
  │ 低碳战略     │ 低碳转型     │
  │ 绿色创新     │ 绿色技术     │
  │ 绿色创新     │ 清洁能源     │
  │ 绿色创新     │ 节能减排     │
  └──────────────┴──────────────┘

  注意：
  - 第一行可以有表头也可以没有（程序自动识别）
  - 同一个关键词不要出现在多个分类中（否则只归入最后一个）


格式二：文本词典（.txt）
--------------------------
  每行一个分类，用冒号分隔分类名和关键词，关键词之间用逗号分隔。

  示例（保存为 UTF-8 编码）：
  ┌─────────────────────────────────────────┐
  │ 低碳战略：碳中和,碳达峰,低碳转型        │
  │ 绿色创新：绿色技术,清洁能源,节能减排    │
  │ ESG披露：ESG报告,社会责任,可持续发展    │
  └─────────────────────────────────────────┘

  注意：
  - 冒号支持中文冒号（：）和英文冒号（:）
  - 关键词分隔符支持逗号、顿号、分号、空格
  - 以 # 开头的行为注释，会被跳过
  - 支持 UTF-8 和 GBK 编码，自动检测

七、输出文件说明
================================================================

输出 Excel 文件包含以下 Sheet：

Sheet1：公司年份分类统计
  - 公司代码：6 位股票代码
  - 年份：4 位年份数字
  - 各分类列：该公司该年份的分类命中总次数
  - 总计：所有分类命中总次数
  - *_TF 列（可选）：TF 标准化词频

  示例：
  ┌────────┬──────┬──────────┬──────────┬──────┐
  │公司代码│ 年份 │ 低碳战略 │ 绿色创新 │ 总计 │
  ├────────┼──────┼──────────┼──────────┼──────┤
  │ 000001 │ 2020 │    15    │    8     │  23  │
  │ 000001 │ 2021 │    22    │    12    │  34  │
  │ 000002 │ 2020 │    5     │    3     │   8  │
  └────────┴──────┴──────────┴──────────┴──────┘


Sheet2：关键词明细
  - 公司代码、年份
  - 关键词：具体命中的关键词
  - 次数：该关键词的命中次数
  - 分类：该关键词所属分类

  仅包含命中次数 > 0 的记录。


Sheet3：分类汇总
  - 分类：分类名称
  - 总次数：该分类在所有数据中的总命中次数
  - 占比(%)：占总命中次数的百分比


Sheet4：命中句子（可选）
  - 公司代码、年份
  - 命中关键词
  - 分类
  - 命中句子：包含关键词的原文句子（截取前 500 字）

  注意：命中句子默认上限 200,000 条，超出后自动跳过。
       若启用 LLM 且勾选「句子上限→不限制」，命中句子提取也将同步不限制。


超大数据集说明：
  如果 Sheet1 或 Sheet2 的行数超过 Excel 上限（约 104 万行），
  程序会：
  1. 先导出完整数据为 CSV 文件（保存在同名_csv 文件夹中）
  2. 再将截断后的数据写入 Excel
  日志中会显示相关提示。

八、常见问题解答
================================================================

Q1: macOS 提示「应用已损坏」或「无法验证开发者」？
A: 这是 macOS 安全机制。解决方法：
   方法一：右键点击 .app → 选择「打开」→ 点击「打开」
   方法二：打开终端，执行：
     xattr -cr /path/to/词频统计分析工具.app

Q2: Windows 下双击 .exe 没反应？
A: (a) 首次启动需要约 10-30 秒的解压时间，请耐心等待
   (b) 查看是否被杀毒软件拦截，添加到白名单后重试
   (c) 确认系统为 64 位 Windows 10 或更高版本

Q3: 打开数据文件报编码错误？
A: 程序自动尝试 UTF-8、GB18030、GBK、Big5 编码。如果仍然
   失败，请将文件用 Excel 打开后另存为 .xlsx 格式。

Q4: 处理大文件时内存不足？
A: (a) 大 CSV 文件（>100MB）会自动分块处理
   (b) 关闭不必要的程序释放内存
   (c) 暂时关闭「导出命中句子」选项
   (d) 分批处理文件夹

Q5: jieba 模式下处理速度很慢？
A: jieba 分词需要对每行文本逐一切词，速度约为正则模式的
   1/5 到 1/10。如果不需要精确的中文分词，推荐使用正则模式。

Q6: 词典中同一个词在多个分类中出现会怎样？
A: 程序会在日志中发出警告，该词最终只会归入最后一个分类。
   建议确保每个关键词只属于一个分类。

Q7: 年份列格式不对怎么办？
A: 程序支持多种年份格式：
   - 纯数字年份：2020
   - 日期格式：2020-03-15、2020/3/15
   - 混合格式（自动识别）
   只要列中有超过 30% 的数据能被正确解析即可。

Q8: 如何在 Windows 上构建 .exe？
A: 将整个文件夹复制到 Windows 电脑，按以下步骤操作：
   1. 安装 Python 3.10+（勾选 Add to PATH）
   2. 双击 build_windows.bat
   3. 等待 2-5 分钟，完成后在 dist 文件夹找到 .exe

Q9: 打包后文件太大（约 90MB）？
A: 这是正常的。打包会包含 Python 解释器和所有依赖库
   （jieba 词典约 15MB、pandas、openpyxl 等）。
   实际运行不受影响。

Q10: 如何更新软件？
A: 用新版 word_freq_analyzer.py 替换旧版，然后重新运行
   构建脚本（macOS: build_app.sh / Windows: build_windows.bat）。
