# 双重实质性双轨独立评分标准

## 用途说明

对同一句子同时输出两个独立分数（各 0-4 分），不再合并为一个总分：

- 物理风险分数 (Physical_Score)：企业是否与实体生态有直接的物理交互
- 转型风险分数 (Transition_Score)：企业是否识别了政策/技术/市场伦理变化带来的商业约束或机遇

两个维度互不干扰，独立评分。与单轨总分的区别：单轨版按最高维度取分（物理3+转型4=总分4），双轨版保留两个维度的独立信息，最终生成两个变量。

---

## 任务定义

判断句子中命中的生物多样性风险词汇，其所在句子与企业自然资本（Natural Capital）的相关性强度，分别从物理和转型两个维度给出 0-4 分。

---

## 核心判断逻辑（双重实质性，双轨并行）

| 维度 | 核心判据 | 典型关键词信号 |
|---|---|---|
| 物理实质性 | 企业是否与实体生态（栖息地、物种、水体）有直接的物理交互（占用、修复、污染、监测、移植等） | 修复、移植、占用、排放、监测站、复垦、种植、巡护 |
| 转型实质性 | 企业是否识别了因政策、技术、市场伦理变化带来的商业约束/机遇，并将其纳入战略叙述 | 政策、法规、标准、框架、认证、战略、转型、合规成本 |

> 关键区分原则："安装了防鸟挡板1200套"——物理得分来自"安装设备改变了鸟类与设施的物理交互"（物理3），转型得分来自"因《野生动物保护法》要求而做"（转型3）。同一句中两维度各自独立打分。

---

## 前置排除规则（两个维度共用）


### A. 非企业行为体排除
若句子主体是政府/NGO/国际组织而非企业自身，两个维度均降一级处理（除非企业明确参与其中）。

### B. 关键词仅命中无实质内容
若命中词仅出现在注册公司名、楼盘名、人名、数字占比中，两个维度均置 0 分。

---

## 物理实质性评分标准 (Physical_Score)

### 物理 0 分：无物理交互

句子中不存在企业实体与自然生态的任何直接物理交互描述。关键词仅用于公司名、楼盘名、人名、营收数字、空洞口号，或句子内容仅涉及转型维度（纯政策叙述）而无物理交互。

判定条件（满足其一即 0 分）：
- 关键词仅用于注册公司名："XX生态科技有限公司"、"XX湿地开发有限公司"
- 关键词仅用于楼盘/项目名："森林半岛小区"、"碧水湾项目"
- 关键词仅用于人名："董事长王森林"
- 纯转型叙述（无物理交互）："公司关注TNFD框架的最新进展"

示例：
```
物理0："公司作为XX生态科技有限公司，始终坚持绿色发展。"
-> 理由："生态"仅用于注册公司名，无物理交互。

物理0："公司持续关注TNFD框架的最新进展，并积极参与行业研讨。"
-> 理由：纯转型/政策关注叙述，无物理交互描述。
```

---

### 物理 1 分：程序性声明 / 否定声明 / 障碍描述 / 机构名罗列

仅为法定合规程序中的物理提及、否定声明（如"不涉及"）、纯物理障碍描述，或机构名罗列，无任何行动意图。

判定条件（满足其一即 1 分）：

| 子类 | 关键特征 | 示例模式 |
|---|---|---|
| 环评/许可中的物理提及 | 仅陈述程序通过，无生态细节 | "项目通过环评"、"取得林业用地许可" |
| 否定声明（无替代方案） | 仅说"不存在/不涉及/未占用" | "不涉及自然保护区"、"未占用基本农田"、"不砍伐原生植被" |
| 物理障碍描述 | 关键词在"阻挡/干扰"语境下 | "树林阻挡信号传输"、"植被影响通风" |
| 机构名罗列 | 仅列举含关键词的机构 | "传育种中心、水产院士工作站、大湖渔业研究院、水生生物资源保护中心" |
| 单纯占地面积提及 | 仅说占地多少亩，无生态评估 | "项目永久占地200亩，临时占地50亩" |

示例：
```
物理1："项目选址不涉及自然保护区、风景名胜区及饮用水源保护区。"
-> 理由：否定声明，仅说"不涉及"，无替代方案或风险分析。

物理1："公司依托传育种中心、水产院士工作站、大湖渔业研究院、水生生物资源保护中心等平台开展研究。"
-> 理由：仅罗列机构名称，无实质物理行动描述。

物理1："该风电场已取得环评批复和林业用地许可。"
-> 理由：仅陈述程序通过，无任何生态评估或行动细节。

物理1："因基站选址周边树木遮挡导致信号衰减，公司进行了枝叶修剪。"
-> 理由：关键词在纯物理障碍语境下出现，无生态考量。
```

### 物理 2 分：减缓 / 规避 / 被动监测 / 供应链基本物理要求

描述了企业为减少或避免对生态环境的物理影响而采取的减缓、规避行动，或委托第三方进行的被动环境监测，或对供应商提出的物理性环保要求。未达到主动生态修复的程度。

判定条件（满足其一即 2 分）：

| 子类 | 关键特征 | 示例模式 |
|---|---|---|
| 减缓措施 | 减少排放/影响，但非主动修复 | "减少废水排放以降低对水生生态影响"、"控制施工扬尘保护周边植被" |
| 主动规避选址 | 避开敏感区，给出替代 | "绕开候鸟迁徙通道"、"避开湿地选址，改为工业用地" |
| 被动监测 | 委托/购买第三方监测服务 | "委托第三方进行环境监测"、"聘请专业机构进行生态调查" |
| 供应链物理要求 | 要求供应商的物理行为 | "要求供应商不砍伐热带雨林"、"供应商不得使用濒危树种" |
| 否定声明+替代方案 | 说了"不"并给出替代 | "避开湿地选址，改为利用工业用地" |
| 多关键词命中 | 物理相关>=2个不同关键词 | 同一句命中>=2个相关关键词且非机构名/口号 |

示例：
```
物理2："为减少施工对沿线植被的影响，公司优化了管道铺设路径，绕开核心林区。"
-> 理由：描述了减缓/规避的物理行动（绕开），但未主动修复或量化成果。

物理2："施工期间，公司聘用了第三方环境监测机构，对项目区水质、空气质量和噪声进行定期监测。"
-> 理由：被动监测（购买服务），非企业自主主动监测。

物理2："公司要求上游供应商确保所采购的木材不来自热带雨林砍伐区域。"
-> 理由：供应链物理要求，但无具体追溯机制。

物理2："经评估后，项目选址避开湿地保护区，调整至工业园区内已有建设用地。"
-> 理由：否定声明+给出明确替代方案，有规避决策过程。
```

---

### 物理 3 分：修复 / 移植 / 保护 / 基线调查 / 持续监测体系

企业主动并直接对生态系统或物种采取的修复、保护、移植、重建、系统性基线调查或建立持续监测体系等行动。关键是**企业主动实施**，而非委托后不管。

判定条件（满足其一即 3 分）：

| 子类 | 关键特征 | 示例模式 |
|---|---|---|
| 主动生态修复 | 企业直接实施的修复 | "对采矿区实施生态修复，种植乡土树种恢复植被"、"边坡采用喷播植草绿化" |
| 物种移植/保护 | 主动移栽、保护珍稀物种 | "对施工区域内珍稀植物进行移植保护"、"设置鱼类增殖站，每年放流鱼苗" |
| 主动监测巡护体系 | 企业建立并运行的体系 | "建立候鸟监测站，开展定期巡护"、"安装红外相机监测野生动物活动" |
| 系统性基线调查 | 全面的生态本底调查 | "委托科研机构对项目区物种多样性进行基线调查"（企业主导，科研机构执行） |
| 湿地/水体重建 | 恢复或重建水体生态 | "建设人工湿地处理尾水"、"恢复河流自然岸线" |
| 生物医药中的动物实验 | 涉及活体动物的深入操作 | "基因修饰动物模型构建到表型分析及药理药效评价" |

物理3与物理2的区分关键：物理2是"减少或避免"负面影响（被动防御），物理3是"主动创造或恢复"正面生态价值（主动进攻）。

示例：
```
物理3："公司对矿区废弃地实施生态修复，采用乡土植物恢复植被，并建立了长期生态监测体系。"
-> 理由：主动修复（种植乡土树种）+自建监测体系，但未给出量化生态成果。

物理3："报告期内，公司围绕模式生物专注于从基因修饰动物模型构建到表型分析及药理药效评价。"
-> 理由：涉及活体生物的深入物理操作，描述了研究过程（若仅提名词则降为物理1）。

物理3："对项目区内发现的6株国家二级保护植物，公司组织专家进行了移植，并设立围栏保护移栽区域。"
-> 理由：主动移植保护珍稀植物+设立保护措施（未量化存活率等，故不到4分）。

物理3："公司建设了一座日处理能力5000吨的人工湿地，用于深度处理工业尾水。"
-> 理由：主动建设生态处理设施，有设计能力描述（若给水质改善数据则到4分）。
```

### 物理 4 分：量化生态成果

在物理3分的主动行动基础上，给出具体量化生态指标：面积（公顷）、种群数量变化、复垦率、覆盖率、存活率、水质指标变化等具体数字。

判定条件（满足其一即 4 分，前提是已有物理3分的主动行动描述）：

| 子类 | 量化方式 | 示例模式 |
|---|---|---|
| 面积量化 | 公顷/亩 | "累计修复湿地500公顷"、"复垦土地1200亩" |
| 比例量化 | 百分比 | "矿区复垦率达到95%"、"植被覆盖率达到92%"、"移植存活率88%" |
| 物种量化 | 物种数/种群数 | "记录到47种鸟类和12种哺乳动物回归"、"鱼类种群数量增加3倍" |
| 水质/生态指标量化 | 具体指标数值 | "人工湿地出水COD降至20mg/L"、"底栖动物多样性指数提升40%" |

注意：若句子只给了数字但无主动行动描述（如"项目占地500公顷"），不能给物理4，只能到物理1。

示例：
```
物理4："公司累计修复矿区生态面积850公顷，植被覆盖率达到92%，监测记录到47种鸟类和12种哺乳动物回归栖息地。"
-> 理由：主动修复+面积量化+覆盖率量化+物种数量化，三维量化。

物理4："报告期内，公司完成边坡绿化45万平方米，栽植乔灌木82万株，草本植物120万平方米，植被成活率达91%。"
-> 理由：主动修复+面积+数量+成活率，多维量化。

物理4："经过五年生态修复，工程扰动区植物物种数从修复前的12种增加到56种，Shannon-Wiener多样性指数从1.2提升至2.8。"
-> 理由：主动修复+物种数+生态指数双重量化。
```

## 转型实质性评分标准 (Transition_Score)

### 转型 0 分：无转型相关叙述

句子中不存在任何政策、法规、市场趋势、技术替代或伦理变化相关的商业约束或机遇叙述。

判定条件（满足其一即 0 分）：
- 纯物理行动描述，无政策/市场/技术变化的叙述
- 纯科学/技术描述，无商业影响分析

示例：
```
转型0："公司对矿区废弃地实施生态修复，采用乡土植物恢复植被。"
-> 理由：纯物理行动描述，无转型维度的政策/市场/技术变化提及。

转型0："经调查，项目区共记录到维管植物86种，鸟类32种，两栖爬行动物8种。"
-> 理由：纯科学调查结果，无任何政策或商业约束/机遇分析。

转型0："公司开发了基于基因编辑技术的新型动物模型构建方法。"
-> 理由：纯技术描述，未涉及动物伦理政策或市场替代趋势。
```

### 转型 1 分：法定合规程序 / 简单政策名词提及 / 机构名罗列

仅提及法定合规程序、政策名称、机构名称，但未展开任何对本公司商业影响的分析。关键词在句子中是"被提到"而非"被分析"。

与转型0的区分：转型0完全没有政策/法规/机构名，转型1有提及但无分析。

判定条件（满足其一即 1 分）：

| 子类 | 关键特征 | 示例模式 |
|---|---|---|
| 法定程序提及 | 说"已完成"无分析 | "已取得环评批复"、"完成竣工环保验收" |
| 政策名词提及 | 提了政策名，无分析 | "响应国家生态保护政策"、"落实绿水青山就是金山银山理念" |
| 机构名罗列 | 列举含政策的机构 | "依托XX生物多样性研究中心" |
| 法规名词提及（无影响分析） | 提了法律名，未说怎么遵守、影响是什么 | "严格遵守《环境保护法》和《野生动物保护法》的规定" |
| 非企业行为的政策转述 | 政府/NGO政策，企业未参与 | "国务院发布了《关于进一步加强生物多样性保护的意见》" |

示例：
```
转型1："项目已取得环评批复和林业用地许可。"
-> 理由：仅陈述法定合规程序通过，未分析这些许可对本公司业务的影响。

转型1："公司严格遵守《中华人民共和国环境保护法》、《野生动物保护法》等相关法律法规。"
-> 理由：提了法律名，但只是"遵守"，未说遵守带来了什么业务变化或成本。

转型1："公司积极响应国家生态文明建设号召，坚持绿色发展理念。"
-> 理由：政策性口号，无实质内容，未披露影响路径。
```

### 转型 2 分：泛政策/泛市场机遇 / 供应链基础要求 / 战略方向宣告

泛泛提及宏观政策方向、市场趋势或行业机遇，但未披露对本公司的具体影响路径或应对策略。或对供应商的基本环保要求，或战略方向宣告但无细节。

判定条件（满足其一即 2 分）：

| 子类 | 关键特征 | 示例模式 |
|---|---|---|
| 泛政策机遇 | 政策带来好处，但没说怎么好、好多少 | "环保政策趋严带来下游需求增长"、"生态文明建设为公司创造新的市场空间" |
| 泛市场趋势 | 市场趋势描述，无本公司应对 | "生物多样性保护催生新的市场机遇"、"消费者对绿色产品需求增加" |
| 行业趋势对标 | 标行业趋势但无自身动作 | "行业正加速向绿色低碳转型"、"同行业公司纷纷加强ESG治理" |
| 供应链基本要求（无追溯机制） | 要求供应商，但未量化 | "要求供应商确保木材来源合法"、"对棕榈油供应商实施追溯管理" |
| 战略方向宣告（无细节） | 宣告要做，但无时间表/预算 | "公司拟将生物多样性纳入全面风险管理体系" |
| 多关键词（含转型） | 转型相关>=3个关键词 | 同一句命中>=3个转型相关关键词且非机构名/口号 |

示例：
```
转型2："随着国家生物多样性保护战略的推进，生态修复市场需求将持续增长，为公司带来发展机遇。"
-> 理由：提及政策带来的市场机遇，但未披露对本公司的具体影响路径。

转型2："公司要求上游供应商确保所采购的棕榈油不来自毁林开垦区域。"
-> 理由：供应链基础要求，但无追溯机制描述（若有"零毁林卫星遥感追溯"则为转型3）。

转型2："未来，公司计划探索基于自然的解决方案在矿区生态修复中的应用。"
-> 理由：战略方向宣告（"计划探索"），但无具体时间表和行动方案。

转型2："随着ESG投资理念的普及，公司面临更多来自投资者关于生物多样性信息披露的询问。"
-> 理由：识别了市场趋势与利益相关者关注，但未说公司如何回应。
```

### 转型 3 分：具体政策/技术对业务的实际产业影响

明确识别某项具体政策、法规、技术变化或市场伦理转向，并描述了该变化对本公司业务模式、运营、产品或战略的潜在实质性影响（威胁或战略调整），或已实施的具体应对行动。

与转型2的区分：转型2泛泛说"政策带来机遇"或"计划做某事"，转型3点名具体政策/法规/标准（有名称或编号），并描述了对本公司的具体影响或已实施的应对行动。

判定条件（满足其一即 3 分）：

| 子类 | 关键特征 | 示例模式 |
|---|---|---|
| 具体政策/法规影响+应对行动 | 点明具体法律，有应对 | "新修订的《野生动物保护法》要求公司调整输电线路设计，增加绝缘装置，已完成全线排查" |
| 行业标准变化应对 | 具体标准变化，有响应 | "新版FSC认证标准增加了高保护价值森林要求，公司已启动供应链合规升级" |
| 技术/伦理替代决策 | 因伦理/法规而主动研发替代 | "为减少动物实验伦理争议，公司投资开发类器官替代技术" |
| 风险识别+启动评估 | 识别具体风险并行动 | "生物多样性丧失可能导致天然原材料供应中断，已启动供应链风险评估" |
| 供应链量化追溯 | 有技术手段的追溯 | "对全部棕榈油供应商实施零毁林卫星遥感追溯" |
| TNFD/披露准备 | 实质性的自然风险披露启动 | "已启动TNFD框架下的自然相关风险识别和披露准备工作" |
| 市场准入/合规门槛应对 | 具体市场准入变化有应对 | "欧盟零毁林法案(EUDR)将于2025年底实施，公司已启动出口产品的可追溯性合规改造" |

示例：
```
转型3："因新修订的《野生动物保护法》对输电线路涉鸟保护提出更高要求，公司已完成全部线路的涉鸟故障隐患排查，并安装防鸟挡板1200套。"
-> 理由：明确识别具体法律+描述全系统性应对行动。

转型3："为应对欧盟零毁林法案(EUDR)的合规要求，公司已对出口欧洲的橡胶和棕榈油产品启动全供应链地理信息追溯，涉及42家上游供应商。"
-> 理由：点名具体国际法规+描述追溯行动的规模和范围。

转型3："考虑到动物福利法规趋严和公众伦理关切，公司董事会批准投资5000万元建设类器官药物筛选平台，减少对实验动物的依赖。"
-> 理由：识别伦理变化趋势+具体替代技术战略决策。

转型3："公司已启动TNFD LEAP方法下的自然相关风险评估，完成对全部15个生产基地的Locate阶段工作，识别出3个高敏感性站点。"
-> 理由：具体框架（TNFD LEAP）+具体评估进展（15个站点，3个高风险）。
```

### 转型 4 分：量化财务影响 / 国家级/全球战略框架对标 / 第三方权威认证

在转型3分基础上，给出量化财务数据（具体金额、成本变化百分比），或明确对标国家级/全球性战略框架并给出具体承诺/行动，或获得第三方权威认证。

与转型3的区分：转型3说了具体政策影响和应对但没给数字，转型4给出了金额/百分比/入口国家级框架/权威认证。

判定条件（满足其一即 4 分，前提是已有转型3分的具体分析基础）：

| 子类 | 量化/对标方式 | 示例模式 |
|---|---|---|
| 量化财务影响 | 具体金额/百分比 | "因环保合规增加运营成本约2000万元"、"生态修复投入占营收3%"、"预计新增合规成本5000万元/年" |
| 全球框架对标+具体承诺 | GBF/COP/SDG | "响应昆明-蒙特利尔全球生物多样性框架30x30目标，承诺2030年供应链零毁林" |
| 国家战略规划对标 | 入选国家规划/试点 | "入选国家山水林田湖草沙一体化保护修复工程试点"、"纳入国家十四五规划重大项目" |
| 获得国家级专项资金 | 具体金额的财政资金 | "获得中央财政专项资金1.2亿元"、"获批生态补偿资金3500万元" |
| 第三方权威认证 | FSC/MSC/RSPO等 | "通过FSC森林认证"、"获得MSC可持续渔业认证" |
| 生态红线/保护地量化 | 红线内的量化成本 | "因公司3座矿山位于生态红线范围内，预计退出成本约2.8亿元" |

示例：
```
转型4："为响应昆明-蒙特利尔全球生物多样性框架的30x30保护目标，公司承诺到2030年实现供应链零毁林，预计新增合规成本约5000万元/年。"
-> 理由：对标GBF全球框架+具体时间承诺+量化财务金额。

转型4："公司入选国家山水林田湖草沙一体化保护和修复工程试点，获得中央财政专项资金1.2亿元，用于3个矿区的生态修复项目。"
-> 理由：入选国家战略试点+量化财政资金+具体项目数量。

转型4："根据最新划定的生态保护红线，公司位于X省的2处矿区部分区域被纳入红线范围，预计需要退出开采，相关资产减值损失约3.5亿元，恢复治理成本约1.2亿元。"
-> 理由：具体政策（生态红线）+量化财务影响（减值+治理成本）双重量化。

转型4："公司旗下5个林场全部通过FSC森林经营认证，认证面积达12万公顷，每年可产生认证木材溢价约800万元。"
-> 理由：第三方权威认证+认证面积量化+财务溢价量化。
```

## 双轨评分快速决策树

### 物理维度决策树

```
句子是否描述企业与实体生态的直接物理交互（占用/修复/污染/监测/移植等）？
├─ 否 → 物理0分
└─ 是 → 是仅程序声明/否定/障碍描述？（如"不涉及"、"已取证"、"树挡信号"）
    ├─ 是 → 物理1分
    └─ 否 → 是减缓/规避/被动监测？（减少影响、绕开、委托第三方监测）
        ├─ 是 → 物理2分
        └─ 否 → 是主动修复/移植/保护/自建体系？
            ├─ 是 → 有量化数字（公顷、物种数、覆盖率）吗？
            │   ├─ 有 → 物理4分
            │   └─ 无 → 物理3分
            └─ 否 → 回到物理2分重新审视
```

### 转型维度决策树

```
句子是否涉及政策/法规/技术变化/市场伦理变化？
├─ 否 → 转型0分
└─ 是 → 仅提名称/程序（"已完成环评"、"遵守XX法"）无影响分析？
    ├─ 是 → 转型1分
    └─ 否 → 泛泛提及政策/市场方向（"带来机遇"、"需求增长"）未说对公司具体影响？
        ├─ 是 → 转型2分
        └─ 否 → 点名具体政策/法规/标准并描述了本公司的应对或影响？
            ├─ 是 → 有量化数据（金额/百分比）或对标国家级/全球框架或获第三方认证吗？
            │   ├─ 有 → 转型4分
            │   └─ 无 → 转型3分
            └─ 否 → 回到转型2分重新审视
```

## 双轨输出格式

```
[物理: X分] [转型: Y分] 原文摘要
物理理由：（一句话说明物理维度评分依据）
转型理由：（一句话说明转型维度评分依据）
```

完整输出示例：

```
[物理:0分] [转型:0分] "公司作为XX生态科技有限公司，始终坚持绿色发展理念。"
物理理由："生态"仅用于注册公司名，无任何实体生态交互描述。
转型理由：空洞口号，无政策/市场变化的具体分析。

[物理:2分] [转型:0分] "为减少施工对沿线植被的影响，公司优化管道铺设路径，绕开核心林区。"
物理理由：描述了减缓/规避的物理行动（绕开），但未主动修复或量化。
转型理由：无转型维度的政策/法规/市场变化叙述。

[物理:0分] [转型:2分] "随着国家生物多样性保护战略的推进，生态修复市场需求将持续增长，为公司带来发展机遇。"
物理理由：无企业与实体生态的物理交互描述。
转型理由：提及政策带来的市场机遇，但未披露对本公司的具体影响路径。

[物理:3分] [转型:0分] "公司对矿区废弃地实施生态修复，采用乡土植物恢复植被，并建立了长期生态监测体系。"
物理理由：主动修复+自建监测体系（物理3），但未量化生态成果。
转型理由：纯物理行动描述，无政策/法规/市场的转型维度叙述。

[物理:0分] [转型:3分] "因新修订的《野生动物保护法》对输电线路涉鸟保护提出更高要求，公司已完成全部线路排查并安装防鸟挡板1200套。"
物理理由：虽涉及物理安装行为，但核心以政策合规描述为主，物理交互细节浅（若描述更多安装细节则为物理2-3）。
转型理由：明确识别具体法律变化+系统性应对行动（转型3），但未量化合规成本。

[物理:4分] [转型:4分] "公司累计修复矿区850公顷，入选国家山水林田湖草沙一体化保护修复工程试点，获得中央专项资金1.2亿元。"
物理理由：主动修复+面积量化（物理4）。
转型理由：入选国家战略试点+量化财政资金（转型4）。

[物理:1分] [转型:4分] "因公司3座矿山位于生态红线范围内，预计退出成本2.8亿元，恢复治理成本1.2亿元，合计约4亿元。"
物理理由：仅描述"矿山位置在红线内"，无企业主动修复保护等物理行动（物理1）。
转型理由：具体政策（生态红线）+退出成本+治理成本双重财务量化（转型4）。
```

## 边界案例处理规则（双维度独立适用）

### 规则1：多关键词命中
若同一句话命中>=3个不同关键词（来自生物多样性词典）且不属于机构名/口号，物理或转型有实质描述的维度至少从2分起评。

### 规则2：前瞻识别vs事后回顾
"拟进行"（前瞻）与"已完成"（回顾）同等对待，看具体程度而非时间维度。

### 规则3：供应链维度(Scope 3)
发生在供应链上下游与自身运营同等对待，物理和转型均不因"是供应商"而降分。

### 规则4：自然资本/生态系统服务概念
若句子含"自然资本"、"生态系统服务"：物理看是否描述对具体服务的物理依赖或交互，转型看是否纳入政策/财务框架。

### 规则5：否定/消极披露分层（双维度独立）

| 表达方式 | 物理评分 | 转型评分 | 举例 |
|---|---|---|---|
| 单纯"不涉及"、"不占用" | 1分 | 0分 | "项目不涉及自然保护区" |
| 否定+给出替代方案（非政策驱动） | 2分 | 0-1分 | "避开湿地选址，改为工业用地" |
| 否定+替代方案（因政策要求） | 2分 | 2-3分 | "因生态红线划定，调整矿区选址至非敏感区" |
| 承认风险存在+正在评估（无物理行动） | 0-1分 | 2-3分 | "生物多样性丧失可能影响原材料供应，已启动评估" |

### 规则6：生物医药实验动物处理

| 语境 | 物理评分 | 转型评分 |
|---|---|---|
| 仅提及"使用动物模型" | 1分 | 0分 |
| 描述具体动物实验操作流程 | 2-3分 | 0分 |
| 描述动物实验操作+提及动物福利伦理 | 2-3分 | 2-3分 |
| 投资开发动物实验替代技术（如类器官） | 0-1分 | 3分 |

### 规则7：公益/捐赠/纯PR行为

| 行为 | 物理评分 | 转型评分 |
|---|---|---|
| 仅提及捐款给环保组织 | 0分 | 0-1分 |
| 举办植树活动（无面积树种描述） | 1分 | 0-1分 |
| 植树活动（有面积/树种/成活率） | 2-3分 | 0-1分 |
| 赞助生物多样性会议/活动 | 0分 | 1-2分 |

### 规则8：ESG报告模板化用语
"我们深知生物多样性保护的重要性，并将持续关注此议题"等模板化套话：物理0分+转型0分。

### 规则9：一句多事，各自取高
若一句话中描述了多个不同水平的物理行动，物理按最高水平评分。转型同理。两个维度独立取高。

### 规则10：两个维度不互相"传染"
物理行动不等于转型识别。"种树"不自动等于"回应政策"。除非句子中明确出现了政策/法规/市场变化的驱动力叙述，否则转型维度不能因物理有分就自动有分。反之亦然——识别了政策影响不等于自动有物理行动。
